# TradeCSV v0.2.0

First exchange format, verified against a real export.

## New

- **OKX 统一交易账单 (unified bill history), Simplified Chinese interface — USDT-margined perpetual swap fills** (`okx-unified-bill-zh/v1`).
  - Recognized from its exact header; the time zone is taken from the export's first line, never assumed.
  - 开多 / 平多 / 开空 / 平空 become fills with `side`, `positionSide` and `positionEffect`; quantity stays in contracts; the fee is normalized (negative in the bill = paid); OKX's realized P&L is passed through.
  - Funding received, automatic margin additions and transfers are counted and listed, not exported as trades. Row types and instruments the evidence did not include are rejected with a code.
  - Each fill is checked against 交易账户余额变动 = −仓位余额变动 + 收益 + 手续费.
- Running the reader on the real export: 195 records, 192 fills accepted, 0 rejected, 3 non-fill rows. The real file is not in the repository; `examples/okx/` holds a synthetic file with the same structure.
- CSV files with mixed CRLF/LF line endings are now read correctly.

## Changed

- Output schemas are now `tradecsv.normalized/0.2` and `tradecsv.report/0.2` (new fields; existing fields unchanged). `totalRecords = accepted + rejected + nonFill`.

## Not covered

OKX English interface, spot and coin-margined rows in the bill, delivery futures, funding paid, liquidations, maker rebates, other exchanges. See `docs/formats.md`.
